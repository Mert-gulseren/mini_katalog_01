# Mini Katalog

## Proje adı

Mini Katalog Uygulaması

## Kısa açıklama

Mini Katalog, Flutter ve Dart ile geliştirilmiş örnek bir mobil ürün kataloğu uygulamasıdır. Uygulamada ürünler görselleri, kategorileri, açıklamaları ve fiyatlarıyla listelenir. Ürün arama ve kategori filtreleme yapılabilir; ürün detayları görüntülenebilir ve ürünler örnek bir sepet durumuna eklenebilir.

Ürün bilgileri, JSON yapısının ve `fromJson` / `toJson` kullanımının gösterilmesi amacıyla uygulama içindeki demo verilerinden yüklenir. Uygulama ek Flutter paketi kullanmaz.

## Kullanılan Flutter sürümü

`flutter --version` çıktısı: **Flutter 3.47.9 • channel stable**

## Çalıştırma adımları

1. Flutter SDK'yı ve Android Studio'yu kurun.
2. Proje klasörünü bilgisayarınıza indirin veya klonlayın.
3. Terminalde proje klasörüne girin.
4. Paketleri hazırlayın:

   ```bash
   flutter pub get
   ```

5. Android emülatörünü başlatın veya Android cihazınızı bağlayın.
6. Uygulamayı çalıştırın:

   ```bash
   flutter run
   ```
